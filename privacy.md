# Privacy policy

Last updated: October 17, 2026

## Who uses this app

gmail-connector is a personal tool used only by its owner, Saiteja Yenugula, with his own Google accounts. It is not offered to anyone else.

## What data it accesses

With the owner's consent, it reads email messages and labels in the owner's own Gmail accounts using Google's read-only Gmail scope. It does not send, delete, or modify any email.

## How data is used

Email content is read only to show the owner summaries and alerts about his own email inside his own Claude Desktop app. It is not sold, shared, or used for advertising.

## Where data is stored

OAuth tokens are stored encrypted on the owner's own computer. The app runs no server and does not upload email or tokens anywhere.

## Google API Services User Data Policy

Use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
