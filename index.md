# gmail-connector

gmail-connector is a personal, single-user tool run by Saiteja Yenugula on his own computer. It gives his own Claude Desktop app read-only access to his own Gmail accounts so it can summarize and flag important email.

It is not offered to the public and has no other users.

It requests only the read-only Gmail scope (gmail.readonly). It cannot send, delete, or change email.

Access tokens are stored encrypted on the owner's own computer and are never uploaded to any server run by this app.
